DNS checklist

  1. Create an A (or AAAA) record for the domain pointing to {{ public_host }}.
  2. Open ports 80 and 443 on the host firewall and the cloud security list.
  3. Save the domain here. nginx is configured automatically and certbot obtains the certificate.
  4. After the automatic restart, use https://{{ status.domain or 'your-domain' }} instead of the IP and port.
