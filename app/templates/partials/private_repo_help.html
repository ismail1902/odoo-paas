The platform clones over HTTPS without prompting, so a private repository needs a read-only token embedded in the URL.

  1. Create a token with read-only repository access:
    • GitHub: fine-grained token, Contents: Read-only
    • GitLab: token with read_repository, or a deploy token
    • Bitbucket: app password with Repositories: Read
  2. Put it in the project's Git URL, for example: https://<username>:<token>@github.com/<owner>/<repo>.git https://oauth2:<token>@gitlab.com/<group>/<repo>.git https://<username>:<app-password>@bitbucket.org/<workspace>/<repo>.git
  3. Use a dedicated, least-privilege token with an expiry. The URL (including the token) is stored in the platform database and shown on the project page to every signed-in user — rotate it if it leaks.
