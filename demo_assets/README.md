# Odoo PaaS demo assets

Captured from an isolated local demo instance with fictional projects and branches.
No live customer data is present.

## Video

- `odoo-paas-demo.mp4` — 1440×900, 36.9 seconds, H.264, Andrew voiceover + ambient bed, no burned-in captions
- `odoo-paas-demo-silent.mp4` — same cut without audio
- `odoo-paas-demo.gif` — 900px silent preview
- `odoo-paas-demo.srt` — narration subtitles for upload as a sidecar file
- `odoo-paas-demo-transcript.txt` — voiceover transcript and timings

Walkthrough: fleet dashboard → project board → branch history → build log →
backups → create-backup wizard → database import with neutralize option →
live monitoring → security settings → GitHub end card.
